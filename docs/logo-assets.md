# SignalPack Logo Assets

Use the Signal Flare mark from the competition visual board.

## In-App Logo

Current in-app assets:

```text
public/brand/signalpack-flare.png
public/brand/signalpack-logo.png
public/brand/signalpack-logo-loop.webp
```

Use the clean Signal Flare mark from the competition board:

- symbol only for app header/icon surfaces
- black background-compatible crop for hero animation
- no extra text baked into the mark for mobile header
- soft crop in the hero so the animation disappears into the black background

For the GitHub README, use `public/brand/signalpack-logo-loop.webp` as the wide animated preview.

## Replace The In-App Logo

Replace the same filenames above to update the app without touching code.

## Replace The PWA App Icon

For the install icon and mobile home-screen icon, also export a square icon version and replace:

```text
public/icon.svg
```

If the source is a PNG, use a transparent `1024x1024` PNG and keep the same visual crop as the app icon exploration in the board.
