# SignalPack Functional QA

Verified on May 17, 2026 against the local Vite app on `http://127.0.0.1:3007/`.

## Responsive Fit

Mobile overflow audit covered:

- Dashboard
- Settings
- Ask Gemma
- Start Alert
- Rapid Packet
- Packet demo output
- History
- Emergency Profile
- Toolkit
- Safety Guide

Result: no document-level horizontal overflow. Settings no longer clips content on the right edge on narrow mobile widths. Intentional off-screen decorative elements, such as the hero logo crop and Leaflet tiles, are clipped by their containers and do not increase page width.

## AI Flow

- Ask Gemma responds through the OpenRouter/Gemma 4 route in the UI.
- Settings connection test uses the same provider path.
- Packets include provider metadata, model name, AI trace, fallback flag, and safety-source metadata.
- If OpenRouter or the selected model is unavailable, the app must show the marked deterministic fallback instead of presenting fallback text as model output.

- print / PDF route

## Export Notes

The in-app Codex browser does not expose a real download manager, so file downloads were verified by exercising the browser export helper with mocked browser APIs:

- `downloadAsFile()` creates Blob URLs, attaches an anchor, triggers click, removes the anchor, and revokes the Blob URL.
- Markdown and JSON filenames are generated by `PacketOutput`.
- Copy, native share, email, and WhatsApp helpers call the expected browser APIs/deep links.

Manual final check in Chrome/Safari: click `Export .MD`, `JSON Dump`, and `Save PDF` from a generated Crisis Packet.
